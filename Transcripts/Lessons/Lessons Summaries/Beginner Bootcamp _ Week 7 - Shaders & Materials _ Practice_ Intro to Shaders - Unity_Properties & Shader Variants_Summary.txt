TITLE: Properties & Shader Variants
OVERVIEW: This lesson explains how to expose Shader Graph controls as material properties and use them to create multiple visual variations from one shader. It also introduces opaque, cutout, and transparent considerations, shadow behavior, and organizing graph sections with labels. It is intended for artists who want reusable, art-directable shaders instead of duplicating the entire graph for every variation.
KEY TOPICS:
- Shader properties
- Material variants
- Surface types
- Transparency and shadows
- Intensity parameters
- Texture properties
- Graph organization
- Reuse
TOOLS / TECHNIQUES / SHORTCUTS:
- Shader Graph Properties

STEP-BY-STEP TAKEAWAYS:
1. Identify which values should be editable outside the shader, such as intensity, color, speed, and texture.
2. Add properties and connect their default values to the appropriate graph inputs.
3. Choose surface behavior deliberately because opaque materials render differently from transparent/cutout materials and affect shadowing.
4. Make the main fire/texture values externally controllable rather than hard-coding them.
5. Save and create material instances/variants with different textures, colors, speeds, and intensities while keeping the base graph unchanged.
6. Organize the graph with labels and groups so collaborators can understand the reusable sections.

ASSIGNMENTS / TIPS:
- Expose the values artists/designers actually need to change.
- Keep the base shader reusable instead of duplicating graphs unnecessarily.
- Consider transparency and shadow behavior when choosing surface type.
- Label graph sections so variants remain maintainable.
