TITLE: Rings, Swipes, & Soulercoasters
OVERVIEW: This lesson presents several ways to construct common VFX meshes including flat rings, sword swipes, and “soul ercoaster” style paths. It emphasizes choosing a modeling strategy based on the desired UV behavior, using curves when a mesh needs customizable paths, and reusing or deforming simple geometry instead of searching for one correct construction. It is aimed at VFX artists who need practical effect-specific meshes.
KEY TOPICS:
- Flat rings
- Swipe meshes
- Curves and Bezier paths
- UV-friendly geometry

- Deformation and path-driven meshes

STEP-BY-STEP TAKEAWAYS:
1. Create a simple flat ring from a cylinder by removing end faces and using inset/scale, then compare its default UV layout.
2. Build the ring instead from the cylinder side surface, deleting top/bottom and scaling a selected edge ring; flatten the result on Z so the side UVs remain useful for scrolling textures.
3. Cut the flat ring in half to make a basic swipe mesh when a simple arc is sufficient.
4. Switch to a Bezier curve when a swipe needs a more controllable/custom path and build the mesh around the curve rather than hand-editing every vertex.
5. Explore “soul ercoaster” style elongated/path-following shapes using the same curve/mesh reasoning.
6. Choose the simplest construction that produces the required silhouette, UVs, and animation behavior; there is no single universally correct VFX mesh method.

ASSIGNMENTS / TIPS:
- Check UVs, not just geometry, when building VFX meshes for scrolling textures.
- Use a curve when path customization matters.
- Start with the simplest viable construction and add complexity only when it solves a real problem.
- Reuse existing meshes when they can be reshaped faster than rebuilding.
- Judge the technique by the final effect and project requirements.
