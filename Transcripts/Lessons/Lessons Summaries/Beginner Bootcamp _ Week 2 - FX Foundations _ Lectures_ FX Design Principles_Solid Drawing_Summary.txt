TITLE: Solid Drawing
OVERVIEW: This lesson explains how to design an effect carefully before beginning a long animation pass. It emphasizes keeping the design appropriate to the artist's current ability, planning the elements and style up front, and staying faithful to the chosen design through the animation. It is aimed at artists who need consistent, animatable FX designs.
KEY TOPICS:
- Pre-animation design
- Simplicity versus complexity
- Planning and “battle plan”
- Design consistency
- Material/style consistency
- Limiting late design changes
TOOLS / TECHNIQUES / SHORTCUTS:
- Multiple state drawings before animation
- Design thumbnails/states
- Reference drawing before animation
- Frame-by-frame consistency checks
STEP-BY-STEP TAKEAWAYS:
1. Identify the purpose of the effect and decide how complex the design should be.
2. Lay out all major design elements before animating, including lines, fills, inner elements, and shadow treatment where relevant.
3. Create representative states or drawings so the intended design language is clear across the action.
4. During animation, continually compare new frames against the original design and stop accidental style drift.
5. Allow only deliberate, limited changes when they genuinely improve the result; avoid introducing a new design system halfway through a long sequence.

ASSIGNMENTS / TIPS:
- Keep beginner designs simple enough to animate confidently.
- Plan major design choices before a long frame-by-frame pass.
- Check every frame against the established design language.
- Treat changes discovered during animation as deliberate exceptions rather than continually redefining the design.
- Use constraints to focus creativity rather than letting scope expand uncontrollably.
