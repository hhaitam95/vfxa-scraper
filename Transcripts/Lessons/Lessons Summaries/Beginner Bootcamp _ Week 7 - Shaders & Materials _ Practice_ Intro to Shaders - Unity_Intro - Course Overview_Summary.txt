TITLE: Intro - Course Overview
OVERVIEW: This lesson introduces the Unity shader and material series and explains why shaders are useful to game VFX artists. It promises a progression from basic material theory through common shader techniques, a complete shader, and more advanced effects. It is intended for artists who are new to shaders or uncomfortable with the technical and mathematical side.
KEY TOPICS:
- Shaders for VFX
- Materials
- Basic theory
- Common shader techniques
- Complete shader construction
- Advanced effects
- Artistic experimentation
TOOLS / TECHNIQUES / SHORTCUTS:
- Unity Shader Graph
- Materials
- Shader properties
- Texture-based effects
STEP-BY-STEP TAKEAWAYS:
1. Start with basic theory about how Unity materials and shaders work.
2. Learn a limited set of common shader techniques that repeatedly appear in VFX.
3. Combine those techniques into a complete shader.
4. Continue into more advanced effects after the foundation is comfortable.
5. Experiment with the tools to create original effects rather than only reproducing demonstrations.
