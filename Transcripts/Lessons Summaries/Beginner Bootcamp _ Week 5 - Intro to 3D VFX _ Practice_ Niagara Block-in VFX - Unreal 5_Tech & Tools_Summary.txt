TITLE: Tech & Tools
OVERVIEW: This lesson introduces three Niagara features that improve technical control and reuse: system-level properties, curve-index sources, and parent emitters. It explains how system and emitter looping differ, how normalized particle age makes curves adapt to variable lifetimes, and how parent emitters can be inherited or detached. It is aimed at beginners who know the basics of Niagara and want more efficient reusable setups.

STEP-BY-STEP TAKEAWAYS:
1. Open the blue system-level settings and distinguish system-wide loop behavior from per-emitter lifecycle settings.
2. Test Infinite, Once, and Multiple system loops and understand that an emitter can either inherit the system's timing or use its own lifecycle.
3. Treat User Parameters as shared variables that can be connected to multiple emitters/modules when a project needs centralized control.
4. Examine Curve Index sources: Particles Normalized Age maps each particle's lifetime to a 0–1 curve, while Delta Time applies behavior according to real elapsed time.
5. Use Emitter Normalized Loop Age when a property should respond to the emitter/system loop rather than each particle's own age.
6. Create a Parent Emitter from an existing emitter, reuse it in another system, and customize or disable inherited module values as permitted.
7. Remove the parent relationship when a copied emitter needs free control over inherited modules that would otherwise remain locked.

ASSIGNMENTS / TIPS:
- Use system-level loop controls deliberately when multiple emitters should share timing.
- Use normalized age for lifetime-relative curves when particle lifetimes vary.
- Prefer parent emitters when many variants genuinely share a strong base; detach when inheritance becomes restrictive.
- Think of user parameters as variables that can centralize controls across a system.
- Do not assume parent emitters are always the best reuse mechanism; straightforward copying can be cleaner for substantially different variants.
