TITLE: Software Setup
OVERVIEW: This lesson configures Toon Boom Harmony for a faster special-effects workflow by simplifying the workspace and adjusting preferences. It covers automatic saving, drawing and timeline options, keyboard shortcuts, panel organization, and removing unused interface controls. It is intended for beginners setting up Harmony before doing the animation exercises.
KEY TOPICS:
- Harmony preferences
- Automatic saving
- Drawing and exposure settings
- Keyboard shortcuts
- Panel layout
- Timeline toolbar cleanup
- Display and workspace efficiency
TOOLS / TECHNIQUES / SHORTCUTS:
- Edit > Preferences
- Automatic Save Scene every 10 minutes
- Dark style sheet
- Extend Exposure of Previous Drawing
- Colored outline
- Reduce indentation
- Advanced App Support overlay/underlay arts
- Edit > Keyboard Shortcuts
- Alt+B for Brush in the instructor setup
- Alt+Shift+W as an alternative personal brush shortcut
- Ctrl+F in Camera view
- Panel docking, splitting, merging, and resizing
- Timeline toolbar Customize
STEP-BY-STEP TAKEAWAYS:
1. Open Harmony Preferences and enable automatic saving at a practical interval.
2. Set the preferred dark style, exposure behavior, colored outline, timeline indentation, and advanced overlay/underlay options.
3. Customize shortcuts around the way you work, including a convenient Brush shortcut.
4. Rearrange, dock, split, merge, and resize panels to keep only the tools needed for the VFX workflow visible.
5. Remove unnecessary toolbar controls and save a cleaner workspace that keeps the camera, drawing, properties, color, library, nodes, and timeline accessible.

ASSIGNMENTS / TIPS:
- Enable automatic saving so a crash does not cost hours of work.
- Treat shortcut choices as personal workflow preferences.
- Keep the workspace focused on the panels actually used for FX work.
- Remove unnecessary reference or toolbar clutter so the application stays responsive and easier to navigate.
