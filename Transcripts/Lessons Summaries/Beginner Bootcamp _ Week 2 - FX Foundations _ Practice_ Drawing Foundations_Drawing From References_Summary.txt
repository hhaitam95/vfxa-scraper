TITLE: Drawing From References
OVERVIEW: This lesson demonstrates how to simplify real reference images into basic three-dimensional forms before adding recognizable details. It uses a paper-like object, a flower, and a fire setup to show how cubes, cylinders, cones, curves, overlaps, and perspective guides can turn complex observations into drawable constructions. It is aimed at artists learning to draw unfamiliar shapes from reference and eventually from imagination.
KEY TOPICS:
- Simplifying references into primitives
- Construction drawing
- Perspective and volume
- Overlap and layering
- Stylization from reference
- Drawing complex objects from new angles
- Dynamic fire shapes
TOOLS / TECHNIQUES / SHORTCUTS:
- Cubes, spheres, cylinders, cones, and ovals as construction forms
- Guide lines and perspective planes
- Light construction strokes followed by darker final lines
- Overlap to communicate depth
- Inner contour lines to suggest volume
- Using reference shapes to reconstruct an object from another angle
STEP-BY-STEP TAKEAWAYS:
1. Look at the reference and identify the simplest solid shapes that can represent its major masses.
2. Draw those primitives in the observed perspective, using them as a structural scaffold rather than trying to copy the final silhouette immediately.
3. Break the primitives into smaller planes, cuts, overlaps, and curves that match the reference.
4. Add recognizable details only after the construction is working, then choose which edges and inner lines to emphasize as the final stylized drawing.
5. Repeat the construction process for another reference or a different camera angle so the simple shapes become reusable mental tools.
6. For dynamic effects such as fire, establish the ground and main masses first, then block the large flame flow and smaller variations before defining the final shapes.

ASSIGNMENTS / TIPS:
- Start with simple primitives that you already know how to draw.
- Use construction to understand the reference instead of copying the outline blindly.
- Do not aim for pixel-to-pixel accuracy; preserve the recognizable essence.
- Use a reference from one angle to learn forms that can later be redrawn from another angle.
- For dynamic effects, block the largest shapes before adding smaller details.
