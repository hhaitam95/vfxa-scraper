TITLE: Fog Breakdown
OVERVIEW: This lesson breaks down a fog effect into large translucent masses, smaller drifting particles, and material-driven softness. It demonstrates using lifetime, size, velocity, and randomness to create atmospheric motion without making the fog look like a collection of identical sprites. It is intended for artists practicing soft environmental effects in Unity.
KEY TOPICS:
- Fog layering
- Soft particles
- Large and small masses
- Drift motion
- Randomness
- Opacity/lifetime
- Depth integration
TOOLS / TECHNIQUES / SHORTCUTS:
- Particle System
- Billboard renderer
- Soft translucent texture
- Size over Lifetime
- Color over Lifetime
- Velocity over Lifetime
- Random rotation
- Depth Fade
STEP-BY-STEP TAKEAWAYS:
1. Block the largest fog masses first so the scene has a readable atmospheric base.
2. Add smaller particles to break up the mass and introduce subtle movement.
3. Use lifetime and opacity curves to avoid uniform fade behavior.
4. Vary size, rotation, and velocity within small ranges so the fog feels organic.
5. Use depth-aware blending where necessary to integrate fog with the ground or other geometry.
6. Review the effect at gameplay distance and reduce density if it starts to obscure the scene.

ASSIGNMENTS / TIPS:
- Avoid identical particle sizes and velocities.
- Keep atmospheric effects subordinate to gameplay readability.
- Use soft depth integration around geometry intersections.
