TITLE: Node-based Shader Interface
OVERVIEW: This lesson introduces Unity's Shader Graph interface and the small set of nodes used throughout the shader series. It covers creating the graph, the Master/Output node, selecting and moving nodes, organizing shader assets, and viewing the material alongside the scene. It is intended for beginners who need to become comfortable navigating Shader Graph.
KEY TOPICS:
- Shader Graph interface
- Node creation and selection
- Master/Output node
- Graph organization
- Scene/material preview
- Post-processing preview
TOOLS / TECHNIQUES / SHORTCUTS:
- Multiply node
- Box select by click-drag
- Shader Graph workspace
- Scene view
- Material preview
- Post Processing setting
- Project folders for shaders
STEP-BY-STEP TAKEAWAYS:
1. Open a Shader Graph and learn where nodes, the graph workspace, and the preview/scene views live.
2. Create and move nodes, box-select multiple nodes, and identify the Master/Output node as the graph's final destination.
3. Save shader assets in a dedicated project folder for organization.
4. Use the graph and scene views together so changes can be evaluated in the world context.
5. Check preview settings such as post processing when the material does not resemble the expected scene result.
