TITLE: Modifiers
OVERVIEW: This lesson introduces Blender modifiers as procedural instructions that can deform and generate geometry without permanently editing the source mesh. It demonstrates Simple Deform, Subdivision Surface, Taper, Bend, Bevel/Decimate, modifier order, and the ability to return to the original mesh while iterating. It is intended for VFX artists who want fast, reusable mesh variants.

STEP-BY-STEP TAKEAWAYS:
1. Move the cube's origin to the ground plane and apply transforms so later modifiers use the desired pivot.
2. Enable Auto Smooth and open the modifier panel.
3. Add Simple Deform and test Twist on the correct axis.
4. Add Subdivision Surface when the base mesh lacks enough cuts for the deformation, and change the modifier order when the mathematical operation needs to happen before or after subdivision.
5. Add other Simple Deform modes such as Taper and Bend, adjusting values while preserving the original source geometry.
6. Explore Bevel, Decimate, and Weighted Normal for rounded or low-poly variations, using enough geometry for the desired result.
7. Duplicate the mesh to create fast variants, then apply/collapse the modifier stack only when the procedural editing stage is finished.

ASSIGNMENTS / TIPS:
- Apply transforms when the modifier's pivot/origin behavior depends on object placement.
- Add geometry when a deformation becomes self-intersecting because the base mesh is too simple.
- Pay attention to modifier order; changing the order changes the result.
- Preserve non-destructive editing while iterating and apply/collapse only when appropriate.
- Duplicate procedural meshes to generate multiple variations quickly.
