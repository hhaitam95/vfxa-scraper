TITLE: Output Pipeline
OVERVIEW: This lesson brings the preceding Unreal material operations together into a practical output pipeline and uses them to build a more complete texture-driven effect. It demonstrates texture sampling, UV manipulation, distortion, interpolation, and time-based motion, while encouraging modular graph organization and reusable controls. It is intended as a capstone for the introductory material operations before more specialized shader techniques.
KEY TOPICS:
- Material output
- Texture-coordinate manipulation
- Texture sampling
- Distortion
- Lerp
- Time-based motion
- Modular graph structure
- Parameter-driven effects
TOOLS / TECHNIQUES / SHORTCUTS:
- Texture Coordinate
- Texture Sample
- Add
- Multiply
- Lerp
- Time
- Panner-like coordinate movement
- Material parameters
- Emissive/Opacity output
STEP-BY-STEP TAKEAWAYS:
1. Start with a sampled texture and identify which part of the graph controls its UV coordinates and which part controls its final color/opacity.
2. Add UV offsets or scaling to create controlled movement.
3. Use another texture or signal to distort the UVs, keeping the distortion amount small enough for readable shapes.
4. Combine layers with Lerp and grayscale masks to select where each texture contributes.
5. Introduce time-driven movement so the materials continue animating without manual frame changes.
6. Organize and expose useful controls, then test the complete material as a VFX rather than evaluating each node in isolation.

- Judge the final material in motion and in the effect context.
