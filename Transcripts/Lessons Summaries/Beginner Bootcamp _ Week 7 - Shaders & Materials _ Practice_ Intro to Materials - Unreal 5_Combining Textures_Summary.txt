TITLE: Combining Textures
OVERVIEW: This lesson explains how multiple grayscale textures can be combined to create richer motion, masks, and layered shapes. It compares operations such as Add, Average, Dissolve, and Lerp and emphasizes that the order of inputs matters. It is intended for beginners learning the core compositing operations used inside Unreal materials.

STEP-BY-STEP TAKEAWAYS:
1. Start with two textures and identify what relationship you want between them: additive buildup, averaging, dissolving, or controlled interpolation.
2. Use Add when both textures should contribute together, keeping in mind that bright values can push the result upward quickly.
3. Use Average/Dissolve-style combinations when the goal is a softer blend rather than simple accumulation.
4. Use Lerp when a third value should decide how strongly the result favors texture A or texture B.
5. Test input order because swapping A and B can change the visual outcome.
6. Combine moving textures and masks deliberately so their interaction creates useful motion rather than visual noise.
